   MyWidgetBox v6.0 - 나만의 감성 데스크톱 위젯 & 애니메이션 캔버스

MyWidgetBox를 이용해 주셔서 감사합니다!
본 프로그램은 설치 과정 없이 압축을 푼 폴더에서 즉시 실행되는 포터블 프로그램입니다.


[1. 실행 방법]
1) 'MyWidgetBox.exe' 파일을 더블 클릭하여 실행합니다.
2) ※ 윈도우 최초 실행 시 "Windows의 PC 보호 (SmartScreen)" 파란색 창이 뜰 수 있습니다.
   -> 이는 개인 개발자 프로그램에 나타나는 정상적인 보안 안내입니다.
   -> [추가 정보] 클릭 후 나타나는 [실행] 버튼을 누르면 정상 실행됩니다.
3) 고화질 동영상(MP4, GIF, WebM 등) 하드웨어 가속 재생을 위한 ffmpeg 엔진이
   프로그램 내부에 자체 내장되어 있으므로, 별도의 코덱이나 프로그램을 설치할 필요가 없습니다.


[2. 주요 기능 및 빠른 시작]
1) 세트(테마) 관리:
   - 상단 우측 [+ 새 세트] 버튼으로 테마별 세트를 생성하고 원하는 위젯들을 담아 관리할 수 있습니다.
2) 새로운 위젯 추가:
   - [새로운 위젯 추가] 버튼을 눌러 개별 이미지/영상 파일 또는 폴더를 선택합니다.
3) ⊞ 스마트 스프레드 (폴더 일괄 자동 배치):
   - 가로 줄 맞춤, 세로 줄 맞춤, 빈칸 자동 채우기 등 원본 비율을 100% 보존하는 스마트 정렬을 지원합니다.
4) ⚡ 스마트 GPU 절전 및 리소스 보호:
   - 컨트롤러 상단 [GPU] 버튼을 눌러 성능 보호를 켜두면, 고사양 게임이나 창 최대화(작업관리자, 웹 브라우저 등)
     작업 시 백그라운드 위젯이 자동으로 일시 정지되어 불필요한 GPU/CPU 리소스 소모를 방지하고 쾌적한 성능을 유지합니다.
5) 윈도우 시작 시 자동 실행:
   - 컨트롤러 상단의 [윈도우 시작 시 자동 실행] 체크박스를 켜두면 PC 부팅 시 바탕화면 위젯이 자동 시작됩니다.


[3. 유용한 단축키 & 마우스 조작]
• Alt + 마우스 좌클릭 (위젯 위) : 위젯 위치 이동 잠금 / 잠금 해제 토글
• Alt + 마우스 휠 (위젯 위)     : 위젯 레이어(바탕화면 배경 ↔ 일반 ↔ 최상위) 즉시 단계 조절
• Ctrl + 마우스 휠 (위젯 위)    : 위젯 불투명도 5% 단위 즉시 조절
• 마우스 우클릭 (위젯 위)       : 화면 크기 맞춤, 인접 빈 공간 밀착 채우기, 상세 설정 바로 열기
• 위젯 카드 더블클릭 (컨트롤러) : 위젯 이름 즉시 변경


[4. 상세 사용 설명서]
프로그램 상단 타이틀바의 [📖 가이드] 버튼을 누르면 모든 기능과 설정 방법이
스크린샷과 함께 친절하게 안내되어 있습니다.
