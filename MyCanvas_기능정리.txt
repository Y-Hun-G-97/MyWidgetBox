MyCanvas 사용자용 기능 정리 (사용법 + 조건별 활용)

1. 프로그램 개요
- 바탕화면에 미디어 위젯(이미지/GIF/영상)을 여러 개 띄우고, 각 위젯별로 재생/표시/동작을 다르게 설정할 수 있습니다.
- 위젯은 `세트` 단위로 묶어서 저장하고, 필요할 때 한 번에 적용할 수 있습니다.

2. 기본 사용 흐름
- 컨트롤러에서 `세트 선택`
- 컨트롤러에서 `＋ 위젯 추가` (추가시에 자동으로 재생버튼이 눌러져 있음)
- `미디어 폴더` 지정 (위젯 화면 위에 폴더 드롭 또는 상세 설정에서 폴더 선택)
- 필요 시 `실행 파일` 지정 (위젯 화면 위에 파일 드롭 또는 상세 설정에서 파일 선택)
- 크기/불투명도/레이어/잠금/재생 옵션 설정 후 `저장`
- 필요 시 위젯 리스트에서 재생/중지 버튼으로 실행 상태 관리
- 실행 중 창 전환이 원하는 대로 안 되면 `포커싱 대상 지정` 후 12초 안에 대상 창을 한 번 클릭해 수동 바인딩

3. 위젯 직접 조작
- `좌클릭`: 연결된 실행 파일 창 포커싱 또는 실행
- `드래그`: 위젯 이동
- `Shift + 모서리 드래그`: 위젯 크기 조절
- `휠`: 미디어 넘기기
- `Ctrl + 휠`: 불투명도 5% 단위 조절
- `우클릭`: `위젯 설정`, `위젯 컨트롤러` 열기
- `폴더 드롭`: 미디어 폴더 변경
- `파일 드롭`: 실행 파일 변경

4. 조건 조합별 추천 사용법
- 월페이퍼처럼 쓰기:
- 조건: `레이어=0(화면 뒤)` + `클릭 잠금=ON`
- 효과: 위젯이 바탕화면 배경처럼 동작하고 마우스 클릭을 가로채지 않습니다.
- 추천 추가 설정: `배경색=투명`, `실행 파일 미지정`, `미디어 맞춤=위젯 채우기(중앙 크롭)`(취향)
- 주의: 잠금 상태에서는 위젯 직접 클릭 조작이 어려우므로 컨트롤러에서 설정을 여는 방식이 안정적입니다.

- 런처 버튼처럼 쓰기:
- 조건: `레이어=1(일반)` + `클릭 잠금=OFF` + `실행 파일 지정`
- 효과: 위젯 클릭으로 앱/게임 실행 또는 기존 창으로 전환하는 런처처럼 사용 가능합니다.

- 항상 위에 띄우는 오버레이:
- 조건: `레이어=2(최상단)` + 필요 시 `클릭 잠금=ON/OFF`
- 효과: 다른 창 위에서도 계속 보입니다.
- 추천: 상태 확인용 영상/GIF 위젯 또는 데코 위젯

- 저사양/발열 관리 우선:
- 조건: `성능 보호=ON` + `영상 전환=싱글` + `영상 디코드=자동/720p`
- 효과: GPU 부담을 줄이고, 고부하 시 자동 일시정지로 끊김/발열을 완화합니다.

- 여러 위젯 동시 편집:
- 조건: 위젯 위에서 `G`로 임시 그룹 등록
- 효과: 이동/크기/불투명도/음소거/잠금 등을 여러 위젯에 동시에 반영할 수 있습니다.

5. 기능별 상세 설명
- 레이어:
- `0`: 화면 뒤(아이콘 위) 느낌. 배경형 위젯에 적합
- `1`: 일반 윈도우와 같은 레벨
- `2`: 다른 창 위로 띄우는 최상단

- 클릭 잠금:
- ON이면 마우스 입력이 위젯을 통과합니다.
- ON일 때는 위젯 직접 드래그/클릭 대신 컨트롤러에서 관리하는 것이 편합니다.
- 잠금 ON 상태에서는 이동/리사이즈 같은 직접 조작이 제한됩니다.

- 미디어 맞춤:
- `원본 유지`: 미디어 비율 유지(여백 생길 수 있음)
- `위젯 채우기`: 위젯 꽉 채움(중앙 크롭)

- 영상 전환:
- `싱글`: 가벼움, 간혹 전환 깜빡임 가능
- `듀얼`: 전환이 더 부드럽지만 메모리 사용 증가

- 영상 디코드:
- `원본`: 품질 우선
- `자동/1080p/720p`: 프록시(저해상도) 활용으로 성능 우선
- `영상 캐시 정리`: 생성된 영상 프록시 캐시 파일을 정리해 용량을 비울 수 있습니다.

- 성능 보호(GPU Guard):
- GPU 사용률이 높으면 영상/GIF 재생을 잠시 멈추고, 내려가면 자동 재개합니다.
- 위젯별 `성능 보호`가 ON인 위젯만 대상입니다.
- 임계값은 컨트롤러 상단 `GPU` 버튼에서 조절합니다.

- 포커싱 대상 지정:
- 실행 파일 매칭 외에 특정 창을 수동으로 지정할 수 있습니다.
- `포커싱 대상 지정` 후 12초 안에 대상 창을 클릭하면 바인딩됩니다.
- 이 기능은 "실행 중인 위젯"에서 설정창을 열었을 때만 활성화됩니다.
- `바인딩 초기화`를 누르면 자동(실행파일 기준) 포커싱 방식으로 되돌립니다.

- 단축키로 가능한 항목 범위:
- 가능: 음소거, 성능 보호, 모서리 모드, 잠금 토글, 임시 그룹, 위젯 종료/설정 열기/컨트롤러 열기, 미디어 넘김, 불투명도 조절
- 불가(설정창 필요): 레이어, 배경색, 미디어 맞춤, 영상 전환, 영상 디코드, 재생 간격 등

6. 단축키 (커서가 위젯 위에 있을 때)
- `M`: 음소거 토글
- `H`: 성능 보호 토글
- `R`: 모서리 모드 토글
- `O`: 위젯 상세 설정
- `P`: 현재 위젯 종료
- `C`: 위젯 컨트롤러 열기
- `G`: 임시 그룹 포함/해제
- `Ctrl+G`: 임시 그룹 전체 해제
- `Alt+클릭`: 잠금 토글

7. 세트/위젯 관리
- `세트 적용`: 선택 세트 구성대로 위젯 일괄 실행
- 세트 적용 시 현재 실행 중 위젯이 정리되고 선택한 세트 기준으로 다시 실행됩니다.
- `세트 관리`:
- 다른 세트 프로필을 현재 세트로 복사
- 세트 삭제 시 프로필 흡수 또는 완전 삭제 선택
- 세트 목록의 이름을 더블클릭하면 세트 이름 변경 가능
- 위젯 리스트:
- `실행/중지/설정/삭제`
- 드래그로 순서 변경
- 더블클릭으로 이름 변경

8. 종료 동작
- 컨트롤러 창 닫기: 트레이로 숨김
- 완전 종료: `프로그램 종료 (Exit)` 또는 트레이 메뉴 `전체 종료`

9. 자주 헷갈리는 포인트
- `＋ 위젯 추가` 직후 위젯은 자동 실행됩니다.
- `세트 적용` 버튼에 `*`가 보이면 현재 선택 세트와 실제 적용 세트가 다르다는 뜻입니다.
- 영상 디코드(자동/1080p/720p) 성능 최적화는 ffmpeg/ffprobe 환경에 따라 체감 차이가 날 수 있습니다.
