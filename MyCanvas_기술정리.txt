MyCanvas 기술 정리 (구조/동작 중심)

1. 기술 스택
- Python + PyQt6
- Win32 API(pywin32, ctypes) 연동 중심 구조(Windows 전용 성격)
- 멀티미디어: `QMediaPlayer`, `QVideoWidget`/`QGraphicsVideoItem`, `QMovie`
- 선택 의존성:
- `win32pdh`: GPU 사용률 샘플링
- `win32com`: `.lnk` 타겟 해석
- `ffmpeg/ffprobe`: 영상 프록시 생성

2. 주요 클래스
- `MasterController`:
- 앱 메인 컨트롤러, 세트/프로필/위젯 인스턴스 수명주기 관리
- 트레이, GPU Guard 전역 폴링, 임시 그룹 동기화
- `DesktopWidget`:
- 개별 위젯 핵심 클래스
- 표시/입력/재생/실행파일 포커싱 로직
- `SettingsDialog`:
- 위젯 상세 설정 UI + 포커싱 대상 캡처 + 영상 캐시 관리
- `SetManagerDialog`:
- 세트 복사/삭제 UI
- `GpuUsageSampler`:
- PDH 기반 GPU 사용률 샘플러

3. 저장 구조(QSettings)
- 마스터: `MyHomeApp / MasterV3`
- 주요 키:
- `profile_ids`, `set_ids`, `current_set_id`, `applied_set_id`
- `sets/{set_id}/name`, `sets/{set_id}/profiles`
- `active_profiles`, `gpu_guard_high_pct`, `gpu_guard_low_pct`
- 프로필: `MyHomeApp / Profile_{id}`
- 주요 키:
- 표시/입력: `w`, `h`, `opacity_pct`, `layer_mode`, `is_locked`, `corner_mode`, `bg_color_mode`
- 재생: `folder_path`, `interval`, `media_fit_mode`, `video_transition_mode`, `video_decode_mode`
- 실행 연동: `exec_path`, `exec_manual_focus_*`
- 기타: `is_muted`, `gpu_guard_enabled`, `quarantined_media`

4. 실행 모델
- `apply_set(set_id)`:
- 기존 위젯 정리 -> 스타트 큐 생성 -> 순차 실행
- 스타트 큐 우선순위:
- 일반 이미지(0) -> 영상(1) -> GIF(2)
- 스타트 간 지연:
- 일반 80ms, GIF 320ms, 영상 450ms
- `run_enabled` 플래그로 프로필 자동 실행 여부 유지

5. 입력/조작 처리
- `DesktopWidget.eventFilter`가 키/마우스 이벤트를 위젯 단위로 처리
- 단축키 처리 조건:
- 커서 아래 최상단 위젯이 자기 자신일 때만 유효
- 키 디바운스:
- `_consume_shortcut_once`(120ms)
- 주요 조작:
- 드래그 이동, Shift+코너 리사이즈, Ctrl+휠 불투명도, 일반 휠 미디어 순환
- 파일/폴더 드롭으로 `exec_path`/`folder_path` 즉시 반영

6. 임시 그룹 동기화
- 컨트롤러가 `_temp_group_ids`로 그룹 멤버 추적
- 그룹 상태에서 팬아웃되는 조작:
- 이동/리사이즈/불투명도
- 음소거/GPU Guard/모서리/잠금 토글
- 위치/크기 저장도 그룹 전체에 반영

7. 미디어 파이프라인
- 지원 확장자:
- png, jpg, jpeg, gif, mp4, avi, mov, ico, jfif, webp
- `update_playlist`:
- 폴더 스캔 + 정렬 + `quarantined_media` 제외
- 전체 격리 시 격리 해제 후 복구
- `next_media` 분기:
- 영상(QMediaPlayer), GIF(QMovie), 이미지(QPixmap), 비어있으면 placeholder
- 단일 파일 최적화:
- 플레이리스트 1개일 때 불필요한 순환 타이머 중지

8. 영상 전환/디코드
- 전환:
- 싱글(단일 플레이어)
- 듀얼(보조 플레이어 선로딩 + 스왑 + 페이드)
- 듀얼은 `QGraphicsVideoItem` 가능 환경에서만 활성
- 디코드:
- 원본/자동/1080p/720p
- 저해상도 모드는 프록시 파일 생성 후 재생 경로 대체
- 프록시 캐시 경로:
- `%LOCALAPPDATA%\\MyHomeApp\\video_proxy_cache`

9. 실행 파일 포커싱 시스템
- 전략:
- 기존 창 포커싱 우선, 없으면 실행
- 매칭 우선순위:
- 바인딩된 HWND -> 수동 바인딩 시그니처 -> 실행파일 경로/프로세스명
- 멀티 위젯 충돌 방지:
- `MasterController._exec_window_claims`로 HWND 소유권 관리
- 포커싱 강화:
- ShowWindow/BringWindowToTop/SetForegroundWindow/AttachThreadInput 순차 시도

10. GPU Guard
- 1초 주기로 GPU 사용률 폴링
- 기본 임계:
- High 90%(일시정지), Low 70%(재개)
- 홀드:
- High 2회 연속 초과 시 pause
- Low 3회 연속 이하 시 resume
- soft recovery 분기 존재(임계 설정이 과격할 때 복귀 보정)

11. 레이어/잠금/아이콘 처리 (mask punch 관련 정정)
- 레이어:
- `0=LAYER_BACK`, `1=LAYER_NORMAL`, `2=LAYER_TOPMOST`
- 잠금 ON:
- `WindowTransparentForInput` 플래그 적용
- 아이콘 처리 기본 경로:
- 현재 기본은 `DesktopIconCloneOverlay`(아이콘/라벨 복제 오버레이)
- punch 방식 사용 여부:
- 완전 제거는 아님
- `clone`을 못 쓰는 조건(예: 특정 비디오 경로/환경)에서 fallback으로 `mask subtract(punch)` 경로가 동작
- 즉, "주 경로는 clone, punch는 예외/폴백"이 현재 코드 상태

12. 수명주기
- 시작:
- `restore_last_session()`에서 세트 복원/적용
- 복원된 위젯이 있으면 컨트롤러는 숨김
- 종료:
- 컨트롤러 닫기는 트레이 숨김
- 완전 종료 시 타이머/샘플러/위젯 정리 후 `app.quit()`

13. 로그 정책(현재 코드)
- 정상 사용자 조작(그룹 토글, 잠금 토글, 단축키 토글 등) 로그는 제거해 콘솔 노이즈를 줄인 상태
- 오류/진단 성격 로그만 유지:
- 실행 실패, 미디어 실패 격리, 듀얼 전환 폴백, 종료 시 예외, 치명 오류
- `MYWIDGET_DEBUG_VIDEO=1`일 때만 영상 디버그 로그 출력
